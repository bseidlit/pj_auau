# pj_auau

Photon and photon-tagged jet analysis code.

- `treeMaking/`, `histMakers/`, `reweightingDer/` and `plotting/` contain the
  existing tree, histogram, reweighting and plotting workflow.
- [histMakers/photonjet](histMakers/photonjet/README.md) contains the copied
  PhotonJetTrees_v1 pipeline for pp and AuAu histogram production, independent
  Condor chunk jobs, checked merging and pp yield/closure. Its input schema and
  commands are documented in that directory.
